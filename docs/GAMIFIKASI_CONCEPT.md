# GAMIFIKASI

## STREAK

Streak menghitung kehadiran. Satu hari kalender WIB terisi bila ada satu aksi nyata:
mengajukan kontribusi (meski masih menunggu),
menyelesaikan verifikasi,
mengajukan ruang diskusi (yang bertanya), atau membalasnya.

Membuka aplikasi, mencari kata, bookmark, vote, dan komentar tidak dapat melanjutkan streak.

Tujuan hari ini adalah aksi itu selesai atau belum. Tidak ada target XP harian, karena kontributor baru menerima XP setelah karyanya disetujui.++

Memerlukan logo streak.
